## Конфигурация opencode

### Файлы
- **Конфиг**: `~/.config/opencode/opencode.jsonc`
- **Ключи API**: `~/.local/share/opencode/auth.json`
- **CLI**: `C:\Users\user\AppData\Local\hermes\node\opencode.cmd`

### Текущая модель
```
deepseek/deepseek-v4-pro
```
Провайдер DeepSeek с ключом `sk-...6d`. OpenRouter удалён.

### Смена модели
- `/models` или `Ctrl+'` — селектор
- `Ctrl+Shift+S` — новая сессия
- Конфиг `model` задаёт модель для новых сессий

## DeepSeek

- Платформа: https://platform.deepseek.com
- API: https://api.deepseek.com
- Модели: deepseek-v4-flash, deepseek-v4-pro, deepseek-chat, deepseek-reasoner
- deepseek-v4-pro: 1M контекст, reasoning, $0.435/$0.87 за 1M токенов

### Установка провайдера
```json
{
  "deepseek": {
    "type": "api",
    "key": "sk-..."
  }
}
```
Добавить в `auth.json`, модель указать в `opencode.jsonc`.
