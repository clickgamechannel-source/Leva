# HackRF One: устройство, возможности и практическое применение

**Кратко**: HackRF One — это открытая аппаратная платформа Software Defined Radio (SDR), позволяющая принимать и передавать радиосигналы в широком диапазоне частот от 1 МГц до 6 ГГц. Устройство подключается к компьютеру по высокоскоростному интерфейсу USB 2.0 и управляется специализированным программным обеспечением. Это полудуплексный трансивер, способный одновременно либо принимать, либо передавать сигнал с полосой до 20 МГц. HackRF широко используется радиолюбителями, исследователями безопасности, инженерами и студентами для изучения беспроводных протоколов, тестирования защищённости систем и проведения радиоэкспериментов.

## Назначение и основные факты

- **Разработчик**: Great Scott Gadgets (Майкл Оссманн).
- **Тип устройства**: SDR-трансивер (приёмопередатчик) с открытой архитектурой.
- **Режим работы**: полудуплекс (одновременно только приём или передача).
- **Совместимость**: Windows, macOS, Linux, одноплатные компьютеры (Raspberry Pi).
- **Программная экосистема**: поддерживается GNU Radio, SDR#, SDR++, Universal Radio Hacker, Gqrx, а также собственные утилиты `hackrf_tools`.
- **Сферы применения**:
  - Анализ и реверс-инжиниринг беспроводных протоколов (Bluetooth, Wi-Fi, DECT, RFID, GSM и др.).
  - Тестирование на проникновение (pentest) радиочастотных систем.
  - Образовательные цели и исследование спектра.
  - Разработка и отладка собственных радиосистем.
  - Любительская радиосвязь и спутниковый приём.

## Технические характеристики

| Параметр | Значение |
|----------|----------|
| Частотный диапазон | 1 МГц – 6 ГГц |
| Полоса пропускания (мгновенная) | до 20 МГц |
| Разрядность АЦП / ЦАП | 8 бит |
| Скорость семплирования | до 20 млн выборок/с |
| Мощность передатчика | до 15 дБм (около 30 мВт) в диапазоне до 4 ГГц, снижается к 6 ГГц |
| Интерфейс | USB 2.0 High-Speed |
| Разъём для антенны | SMA female |
| Встроенный тактовый генератор | 20 МГц TCXO (опционально синхронизация от внешнего опорного генератора) |
| Питание | по USB (5 В, до 500 мА) |
| Размеры (плата) | примерно 120 × 80 мм |
| Дополнительные интерфейсы | порт расширения с линиями GPIO, CLK, I/Q |
| Совместимость с ПО | libhackrf, hackrf_tools, GNU Radio, SDR# (плагин), SDR++, Gqrx, URH, QSpectrumAnalyzer |

Примечание: из-за 8-битного преобразования динамический диапазон ограничен, что следует учитывать при работе со слабыми сигналами в присутствии мощных помех.

## Цены

Ориентировочная розничная стоимость оригинального HackRF One составляет **$300–350** без учёта доставки и налогов. У официальных реселлеров цена в РФ может достигать 45 000 – 55 000 рублей в зависимости от курса и комплектации (антенны, корпус, кабели). Клоны (реплики) можно приобрести по цене от **$100–150**, однако их качество и стабильность работы могут существенно отличаться. В комплект для начала работы рекомендуется добавить набор антенн для разных диапазонов (примерно $20–50).

## Установка и настройка

### 1. Подключение и драйверы
- Подключите HackRF к USB-порту компьютера. Используйте качественный кабель и при необходимости внешний USB-хаб с дополнительным питанием.
- Для Windows потребуется установить драйвер с помощью Zadig (инструмент из комплекта драйверов WinUSB). Рекомендуется следовать официальной инструкции Great Scott Gadgets.
- В Linux и macOS устройство обычно определяется автоматически; достаточно установить библиотеку `libhackrf` и пакет `hackrf_tools` из репозитория или собрать из исходников.

### 2. Базовое программное обеспечение
- **hackrf_tools** — набор утилит командной строки для приёма/передачи, управления частотой, усилением и режимами. Пример команды приёма:
  ```
  hackrf_transfer -r capture.iq -f 433920000 -s 8000000
  ```
- **GNU Radio** — среда визуального программирования цифровой обработки сигналов. Блоки `osmocom Source/Sink` или `HackRF Source/Sink` позволяют быстро создавать схемы приёма и передачи.
- **SDR# (SDRSharp)** — популярный Windows-анализатор спектра с плагином для HackRF. Удобен для визуального мониторинга и демодуляции аналоговых/цифровых сигналов.
- **SDR++** — кроссплатформенный SDR-клиент, нативно поддерживающий HackRF.
- **Universal Radio Hacker (URH)** — специализированный инструмент для анализа и воспроизведения сигналов цифровых протоколов.
- **Gqrx** — простой приёмник для Linux/macOS, работающий через GNU Radio.

### 3. Типовой рабочий процесс приёма
1. Подключите антенну, соответствующую целевому диапазону частот.
2. Запустите SDR-приложение (SDR#, SDR++ или Gqrx).
3. Выберите HackRF в качестве устройства ввода.
4. Установите центральную частоту и коэффициент усиления:
   - Усиление приёмника (LNA) настраивайте осторожно: 0–14 дБ для слабых сигналов, 0 дБ для сильных, чтобы избежать перегрузки.
   - Усиление ПЧ (IF) обычно оставляют 16–40 дБ.
5. Наблюдайте спектр, захватывайте интересующие сигналы в файл `.iq` для последующего анализа.

### 4. Передача сигнала
- Перед началом передачи обязательно убедитесь в наличии разрешения на использование выбранной частоты или работайте в безлицензионных диапазонах (LPD 433 МГц, SRD 868 МГц, ISM 2,4 ГГц с ограниченной мощностью).
- Сформируйте IQ-файл или используйте генератор сигналов в GNU Radio.
- Отправьте данные утилитой:
  ```
  hackrf_transfer -t signal.iq -f 433920000 -s 2000000 -a 1 -x 20
  ```
  где `-a 1` включает усилитель передачи, `-x 20` задаёт усиление в дБ.
- Контролируйте уровень выходной мощности и избегайте длительного излучения без нагрузки на антенну.

## Рекомендации по эксплуатации

- **Юридическая ответственность**: использование HackRF для передачи на частотах, требующих лицензирования, или для создания помех запрещено в большинстве стран. Перед работой изучите местное законодательство в области радиосвязи.
- **Аттенюация**: при подключении к антенне сильных передатчиков или в лабораторных условиях используйте внешние аттенюаторы, чтобы не повредить входные каскады.
- **Экранирование и заземление**: высокочастотные помехи от компьютера могут влиять на качество приёма. Рекомендуется применять ферритовые фильтры на USB-кабеле и использовать корпус с экранировкой (оригинальный HackRF One может продаваться без корпуса — докупите его отдельно или распечатайте на 3D-принтере).
- **Охлаждение**: при длительной передаче микросхема может нагреваться; следите за температурой, особенно в пластиковом корпусе.
- **Антенны**: для широкополосных экспериментов удобны логопериодические или дискоконусные антенны. Для узкополосных — настроенные штыревые или патч-антенны.
- **Обновление прошивки**: периодически обновляйте CPLD-прошивку и микроконтроллер через `hackrf_spiflash` для исправления ошибок и улучшения стабильности.
