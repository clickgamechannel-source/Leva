# Беспроводной видеоприемник 5,8 ГГц OTG‑типа для FPV-систем (на примере Eachine ROTG01)

**Кратко**  
Малогабаритный приемник видеосигнала диапазона 5,8 ГГц с интерфейсом USB OTG. Предназначен для трансляции изображения с FPV-камер или видеопередатчиков дронов на смартфон/планшет под управлением Android. Расширяет функциональность стандартных очков‑приёмников, позволяя записывать полётное видео и использовать телефон в качестве бюджетного монитора.

---

## Основные факты
- **Тип устройства:** аналоговый видеоприемник 5,8 ГГц (40 каналов) с выходом USB OTG.
- **Области применения:** FPV-пилотирование (квадрокоптеры, самолёты, машинки), системы видеонаблюдения на основе аналоговых камер, проверка сигнала беспроводных передатчиков.
- **Совместимость:** Android-устройства (4.1 и выше) с поддержкой OTG. Рекомендуется приложение Go FPV (разработчик — Eachine) или сторонние UVC‑приложения.
- **Дополнительные функции:** запись видео и скриншотов непосредственно в память телефона; работа без внешнего аккумулятора (питание осуществляется через USB порт смартфона).
- **Комплектация:** приемник, USB‑кабель OTG, антенна (обычно диполь, RP-SMA), инструкция.
