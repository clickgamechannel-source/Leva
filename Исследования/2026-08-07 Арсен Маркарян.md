# Арсен Маркарян: основатель BestChange и предприниматель в сфере криптофинансов

## Кратко
Арсен Маркарян — российский предприниматель, сооснователь и генеральный директор BestChange, крупнейшего в СНГ агрегатора обменных пунктов электронных валют и криптоактивов. Под его руководством платформа стала ведущим инструментом для мониторинга курсов и безопасного выбора обменных сервисов. Активно участвует в отраслевой дискуссии о регулировании крипторынка.

## Основные факты
- **Основание BestChange**: В 2007 году совместно с партнёрами запустил сервис мониторинга обменников, который сегодня агрегирует предложения более 500 верифицированных пунктов.
- **Лидерство**: Занимает пост генерального директора, определяет стратегию развития компании, ориентированную на прозрачность, скорость и безопасность транзакций.
- **Преодоление блокировок**: В 2017 году сайт BestChange был внесён в реестр запрещённых в РФ по решению суда (иск прокуратуры). Маркарян организовал работу через зеркала и юридически оспаривал решение. В 2018 году блокировка была снята после признания действий надзорных органов незаконными.
- **Развитие рынка**: Неоднократно выступал за создание понятных регулирующих норм для криптообменного бизнеса в России, участвовал в профильных конференциях (Blockchain Life, Crypto Summit) и давал комментарии ведущим деловым СМИ.
- **Дополнительные проекты**: Информация о других бизнесах ограничена; основное внимание в публичном поле уделено BestChange и смежным направлениям мониторинга финансовых сервисов.

## Цены (применимо к платформе BestChange)
Услуга мониторинга для конечных пользователей полностью бесплатна. Обменные пункты, интегрированные в систему, платят фиксированную комиссию или абонентскую плату за листинг и поддержку (детали коммерческого соглашения не раскрываются публично). Пользователи не несут дополнительных расходов — курсы отображаются с учётом всех комиссий обменника.

## Технические характеристики платформы BestChange
- **Скорость обновления данных**: Курсы обновляются в реальном времени (задержка не превышает 3–5 секунд). Данные запрашиваются по API обменных пунктов или посредством периодического опроса.
- **API для партнёров**: Доступен REST API для получения курсов, резервов, отзывов. Формат ответа — JSON. Ключ API выдаётся после регистрации партнёрского кабинета.
- **Защита от DDoS**: Применяются сервисы фильтрации трафика (например, Cloudflare) и распределённая серверная архитектура для обеспечения доступности даже в условиях атак.
- **Безопасность соединения**: Взаимодействие с сайтом осуществляется по протоколу HTTPS с использованием современных TLS-сертификатов. Проверка статуса обменных пунктов ведётся непрерывно с автоматическим отключением нестабильных партнёров.
- **Масштабируемость**: Система поддерживает одновременную обработку десятков тысяч запросов курсов и выдерживает пиковые нагрузки во время резких движений рынка.
- **Доступность**: Основной сайт и зеркала работают с минимальным временем простоя (целевой uptime — 99,9 %).
